## The ask

Add an option under **Equipment** in the Service Request **create** form labeled **"Not Available"**.

## Why

To allow a user to create a **general** service request at the **lead level** that is not tied to any specific piece of equipment.

Today the SR create form forces an equipment selection, which prevents users from filing general lead-level service requests.
