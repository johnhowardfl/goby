After the V3 launch in April 2023, the **legacy V2 application** was kept running in parallel for several weeks, then decommissioned in mid-2023.

## What "Legacy" means

The "Legacy Application" referenced in 2023 emails is **LeadSpeed V2**. After V3 went live on 2023-04-18 (see [v3-launch-april-2023](./v3-launch-april-2023.md)), V2 stayed up to provide a fallback and reference point for users transitioning to V3.

## Decommissioning timeline

- 2023-05-25 — Varun to John: *"As we are getting closer to the Deadline discussed earlier for Decommissioning Legacy Application, we would need your approval to proceed further. We have reduced the cost by 50%."* John was asked for the green light.
- The cost-reduction-by-50% language suggests Saksoft had been quoting the decommissioning effort and trimmed scope (or trimmed Azure tear-down work) to make it more palatable.
- The actual sunset of V2 happened in this window. Exact final date is not in the email record visible — confirm with Saksoft if a precise V2 sunset date is needed.

## What this means for current state

- V2 / Phoenix / `phoenix.leadspeed.me` is **gone** as a live app. Don't assume any V2 URL is reachable.
- All historical V2 data that was important enough to retain was **migrated to V3 in April 2023**. If a piece of historical data isn't in V3, it likely was either left behind intentionally or never made the migration. Saksoft/Leela can do data archaeology if a missing historical record is critical (the Apr 2026 Scott Griffith data extract is an example pattern).
- Anyone referencing V2 as if it's current is referring to historical state, not live.
